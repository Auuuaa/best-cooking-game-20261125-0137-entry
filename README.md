**Sizzle Station** — a lightning-fast kitchen rush. Take tickets from the order board, chop lettuce and tomato, grill patties, fry potatoes, stack dishes on plates at the assembly counter and serve them at the window before patience runs out. A 150-second shift, 3 hearts, combos for fast service, and pressure that ramps up as orders pile on.

A complete, original, offline 2D canvas game: keyboard (WASD/arrows + E) and mouse (click a station to walk over and use it), synthesized WebAudio sounds, zero network requests, zero asset files — every sprite is drawn in code.

## Play it

```sh
node serve.ts   # serves game/ at http://localhost:8080
```

Or open `game/index.html` from any static server.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `game/` and `screenshots/` to the output folder and writes `dossier.json` with the vendored `makefun-game.ts` library.
